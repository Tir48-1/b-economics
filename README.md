# b-economics.com

Static site for BEconomics, served by GitHub Pages.

- All copy lives in `tools/content.py`.
- Run `python3 tools/build.py` to regenerate every page, `sitemap.xml` and `llms.txt`.
- Styles: `assets/site.css`. Script (menu, contact form): `assets/site.js`.
- The contact form posts to FormSubmit (formsubmit.co); the first submission sends an activation email to tiran@b-economics.com.
